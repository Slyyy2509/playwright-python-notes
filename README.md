# Практическая работа по Playwright

Учебный проект по изучению автоматизированного тестирования веб-приложений с использованием Python и Playwright.

## Информация о студенте

- **ФИО: Быковский Андрей Максимович
- **Язык программирования:** Python 3.11.3
- **Инструмент:** Playwright
- **Операционная система:** Windows

## Цель работы

Изучить возможности Playwright, научиться автоматизировать действия в браузере, работать с веб-страницами и выполнять проверки элементов веб-приложений.
